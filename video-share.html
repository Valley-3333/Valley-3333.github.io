相手に見せるまでの3ステップ

  1. 共有したい動画ファイルを videos/ フォルダの中に保存します。（例: videos/sample.mp4）
  2. ターミナルやGitHub Desktopでコミット＆プッシュします。
    git add videos/ → git commit -m "Add video" → git push
  3. このツールで生成したURLを、見せたい相手にチャット（DiscordやDM等）で送るだけで完了です！
